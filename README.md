# Z. — Social Links V2

A hand-built, responsive GitHub Pages site based on the supplied design reference, rebuilt with a cleaner layout and multiple scroll sections.

## Structure

```text
z-social-links-v2/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── profile.jpg
    └── mountain.jpg
```

## Change your links

Open `index.html` and replace these URLs:

- Instagram: `https://instagram.com/`
- YouTube: `https://youtube.com/`
- X: `https://x.com/`
- Discord: `https://discord.com/`
- Telegram: `https://t.me/`
- GitHub: `https://github.com/`

## Change your pictures

Replace:

`assets/profile.jpg`

`assets/mountain.jpg`

Keep the same filenames so you do not have to change the HTML/CSS.

## GitHub Pages

For a personal GitHub Pages site, create a repository named:

`YOUR_USERNAME.github.io`

Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the root of the repository.

Then go to:

**Settings → Pages → Deploy from a branch → main → / (root) → Save**

The site does not require Node.js, npm, a database, or a backend.
